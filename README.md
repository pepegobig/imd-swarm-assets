# IMD Swarm assets

Public brand assets for videos and posts that the IMD swarm makes for Lobby (neighborslobby.com, @imdpepe).
IMD jobs can start from this repository (`repoUrl` and `baseCommit`), so the swarm's workers see these files.

- `brand.md`: the exact Lobby x IMD Swarm palette, gradients, glows and type.
- `infographics/swarm-content-creator.png`: "The swarm is now a content creator." (1080x1350).
